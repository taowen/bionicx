# VLC AVI fixture on the shared seed

VLC `3.0.23-0+deb13u1` is `ii` on seed `ed998c09…`. The controlled
`vlc-avi-probe` loads Debian `libvlc.so.5` with dummy input/output and
requires the shared `bionicx-motion-audio.avi` (90 I420 frames + 48 kHz
PCM) to enter Playing at `320x180` for 3000 ms. Result: 10/10.

Untraced `profiles/vlc.json` then loops the same AVI through `xcb_x11`
and PulseAudio. After the Qt interface comes up, the compositor shows
the moving colour bars. PulseAudio reports an active track. D-Bus
interface init fails (`dbus-launch`); VLC falls back to the default Qt
UI. That is not treated as a playback failure.

No per-app library copy, `LD_LIBRARY_PATH`, or VirGL.
