# XKB keyboard and key names

Once core device metadata succeeded, WPS/Qt advanced to XKB minor opcode 17,
`GetNames`. A silent acknowledgement would leave xkbcommon without component,
type, or physical-key identities, so BionicX returns an actual name model.

The server reports the requested subset of six component names, four required
key-type names, and physical names for keycodes 8 through 255. Keycode 9 is
named `ESC`; other currently generic keys have stable four-byte `Knnn` names.
Every name atom is interned in the same global atom table used by core X11.

The AArch64 glibc desktop probe calls `XkbGetNames` via libX11 and checks the
symbols atom, first key-type atom, and Escape key name. Its raw 5/5, zero-error
run is in `evidence/x11-desktop-probe-xkb-names.log`.

WPS now completes startup without an unimplemented XKB request or either prior
`qt.qpa.xcb` warning. The next active gap is XI2 minor opcode 46
(`XISelectEvents`), visible in `evidence/wps-xkb-names-fixed.log`.
