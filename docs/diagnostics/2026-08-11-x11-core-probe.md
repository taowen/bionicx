The nonzero client exit is intentional while these regressions remain open.

## Gaps exposed

1. `XListExtensions` returned an empty list. Logcat showed
   `Unsupported opcode 99`, even though `XServer` has BIG-REQUESTS, DRI3,
   Present, Composite and GLX handlers. This needs a real ListExtensions reply.
2. `XDrawString` generated `Unsupported opcode 74` (PolyText8).
3. The screenshot was white except for the child background. Source inspection
   found `polyFillRectangle` applying `GraphicsContext.getBackground()` rather
   than the protocol-defined foreground pixel. Pixel readback is now part of
   the regression so accepted requests cannot masquerade as rendered output.
4. ADB-injected tap/swipe/key input produced zero client events. This remains
   an observation until the Android event route is isolated independently.
