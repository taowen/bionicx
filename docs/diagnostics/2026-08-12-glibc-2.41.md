# Android-compatible glibc 2.41

Debian 13 trixie packages are built against glibc 2.41, while BionicX still
provided an Android-compatible 2.39 runtime. The runtime builder now pins GNU
glibc 2.41 (`a5a26b...e901`) and termux-pacman/glibc-packages commit
`0bd35594050d283eda7b23a3d9cfa28fd11c0b15`.

The termux patch set disables Android-blocked `set_robust_list`, but continued
to define glibc's `__ASSUME_SET_ROBUST_LIST`. That compiled out glibc's existing
userspace thread-exit fallback. The first x300 run consequently passed every
other runtime check but timed out acquiring a process-private robust mutex
after owner death.

`runtime/glibc/2.41/zz-bionicx-robust-fallback.patch` removes that false kernel
assumption. The fallback is allowed only for process-private, non-PI robust
mutexes because userspace cannot reproduce kernel cleanup across processes or
priority-inheritance state.

The rebuilt runtime reports glibc 2.41 and passes the complete untraced x300
probe under the ordinary Android app UID:

```text
BXTEST PASS runtime-identity glibc=2.41 pid=6526 page=4096
BXTEST PASS pthread-create-join
BXTEST PASS pthread-robust-mutex isolated-exit=0
BXSUMMARY runtime passed=20 failed=0
runtime-probe exited with 0
```

The retained raw result is `evidence/runtime-probe-glibc-2.41.log`.
