# BionicX Android host

This is the embedded X11 display/input host. Its X server and renderer are
derived from Winlator commit `c2f4ad4534f4637b543a9a3b085e28f50cf6d01c`
and retain LGPL-2.1 licensing.

Build from the repository root with `tools/build.sh`; the generated executor,
compatibility libraries, Gradle outputs, and APK are intentionally ignored.
